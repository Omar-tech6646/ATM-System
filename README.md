ATM System

A console-based application using c++ that simulates an Automated Teller Machine (ATM) and provides users with basic banking services.

 Overview

The ATM System is a console application designed to simulate the functionality of a real ATM. It allows users to access their bank accounts, check balances, withdraw cash, and deposit money through an interactive menu.

The project focuses on implementing essential banking operations while practicing programming fundamentals, data management, and problem-solving skills.

Features

* User Authentication: Allows users to access their accounts using account credentials or PIN codes.
* Balance Inquiry: Display the current account balance.
* Quick Withdraw: Withdraw predefined amounts quickly.
* Normal Withdraw: Allow users to enter a custom withdrawal amount.
* Deposit: Add money to the account balance.
* Account Information: Display customer account details.
* Transaction Processing: Perform and manage basic ATM transactions.
* Input Validation: Validate user input and prevent invalid transactions.
* Interactive Menu: Navigate through ATM services using a console-based menu.
